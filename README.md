# 🏥 Antrian Klinik

Aplikasi Android untuk mengelola antrian pasien di klinik secara digital. Aplikasi ini membantu petugas dalam mengatur proses pendaftaran pasien, pemberian nomor antrian otomatis, pemanggilan pasien, pencarian data, serta penyimpanan riwayat pasien.

## Fitur

- Splash Screen
- Login Admin
- Dashboard Antrian
- Tambah Data Pasien
- Nomor Antrian Otomatis
- Detail Pasien
- Panggil Pasien
- Riwayat Pasien
- Pencarian Pasien
- Reset Antrian Harian
- Dark Mode

## Teknologi

- Java
- Android Studio
- SQLite
- Material Design
- RecyclerView
